# کالای آشپزخانه لوکس – فرم سفارش ایتا

این برنامه یک فرم وب ثبت سفارش دارد و بعد از ثبت، سفارش را با API رسمی مستندشده ایتا به `chat_id` تنظیم‌شده اطلاع می‌دهد.

## فایل‌ها
- `Main.py`: برنامه Flask
- `requirements.txt`: وابستگی‌ها
- `render.yaml`: تنظیم اولیه سرویس Render

## نکته مهم درباره ایتا
توکن را فقط در Render Environment Variables وارد کنید، نه GitHub و نه چت.
مقدار `EITAA_CHAT_ID` باید شناسه مقصدی باشد که طبق مستندات ایتا اجازه دریافت پیام را داده است. ارسال پیام به کانال باید با دسترسی و شناسه مقصد واقعی شما آزمایش شود؛ موفقیت آن از پیش تضمین نشده است.
این نسخه فرم سفارش وب است، نه رباتی که پیام‌های ورودی چت را می‌خواند.

## Render
Build: `pip install -r requirements.txt`
Start: `gunicorn Main:app`
Health: `/health`

برای نگهداری مطمئن سفارش‌ها بعد از restart یا deploy، باید دیسک پایدار یا PostgreSQL به سرویس وصل شود. فایل SQLite محلی در پلن رایگان ممکن است از بین برود.
